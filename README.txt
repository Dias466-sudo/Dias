САЙТ ДИАСА — ФАЙЛЫ ДЛЯ VERCEL
==============================

ФАЙЛЫ (все лежат в одной папке, без подпапок)
----------------------------------------------
index.html     главный сайт        ->  вашсайт.vercel.app
kp.html        КП с ценой          ->  вашсайт.vercel.app/kp
og.png         превью главной в WhatsApp
og-kp.png      превью КП
favicon.svg    иконка во вкладке
robots.txt     закрывает КП от Google
vercel.json    настройки (благодаря им kp.html открывается как /kp)

ЗАЛИВКА
-------
1. Сложите все файлы в одну папку, например  dias
2. vercel.com  ->  зарегистрируйтесь (бесплатно, можно через Google)
3. Откройте  vercel.com/drop
4. Перетащите папку целиком
5. Название проекта, например dias  ->  Deploy

Готово. HTTPS включится сам.

ПОСЛЕ ЗАЛИВКИ (по желанию)
--------------------------
Чтобы в WhatsApp показывалась картинка превью, а не пустой блок:
в index.html найдите
    <meta property="og:image" content="/og.png">
замените на
    <meta property="og:image" content="https://ВАШ-АДРЕС.vercel.app/og.png">
в kp.html — то же самое с og-kp.png
и залейте папку заново.
